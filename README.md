# Rune's Nextbot Resource Pack Maker

A browser-based resource pack maker for Rune's Nextbot, a Minecraft mod. Create custom Nextbots with your own images and sounds!

## Open the maker

[Nextbot Maker (GitHub Pages)](https://shigurerune.github.io/runes-nextbot-resourcepack-maker/)

The project page uses the GitHub account name `ShigureRune` and the repository path `runes-nextbot-resourcepack-maker`.
